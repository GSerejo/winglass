# WinGlass · site

Site oficial do **WinGlass**, o Liquid Glass para o Windows 11.

- 🌐 **Site:** https://gserejo.github.io/winglass/
- ⬇️ **Baixar na Microsoft Store:** https://apps.microsoft.com/detail/9NJP11JXN4S9
- 🔒 **Política de privacidade:** https://gserejo.github.io/winglass/privacidade.html

Páginas estáticas (HTML, CSS e um pouco de JavaScript), sem bibliotecas externas nem rastreamento, publicadas pelo GitHub Pages. O código do app fica no repositório [GlassShell](https://github.com/GSerejo/GlassShell); estas páginas são uma cópia de `docs/site` de lá.
